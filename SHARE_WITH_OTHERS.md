# Sharing Tellum Ultimum with someone who doesn't have Python

They do **not** need Cursor, Python, or any developer tools.

## What you do (one time)

1. On your PC, double-click **`build_portable.bat`**
2. Wait 5–10 minutes (downloads Python + installs dependencies)
3. When finished, find:
   - **`dist\TellumUltimum_Portable.zip`** — send this file
4. Upload to Google Drive, Dropbox, WeTransfer, etc. (zip is ~200–400 MB)

**Do not** include your `TellumUltimumData` folder — that is your private health data.

## What they do

1. Unzip `TellumUltimum_Portable.zip` anywhere (e.g. Desktop)
2. Double-click **`Start Tellum Ultimum.bat`**
3. Browser opens to the app — done

To quit: close the black command window.

## Optional: screenshot OCR

For automatic text from FatSecret / Oura screenshots, they can install **Tesseract OCR** for Windows (separate one-time install). Without it, the app still runs; they enter values manually or paste text.

## If the zip is too large to email

Use Google Drive, Dropbox, or WeTransfer. Or copy the unzipped `TellumUltimum_Portable` folder to a USB drive.
